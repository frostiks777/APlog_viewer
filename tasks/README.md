# tasks/

Файлы задач нетривиального размера — процесс и статусы описаны в скилле
[task-file](../.agents/skills/task-file/SKILL.md).

- Точечные правки (одна функция, опечатка, локальный fix) сюда не заводятся — сразу в код.
- Одна задача — один каталог: `tasks/<YYYY-MM-DD>-<slug>/task.md`.
- Шаблон для копирования — [`TEMPLATE.md`](TEMPLATE.md).
- План, решения, evidence и handoff живут в том же `task.md`; отдельного spec/state-файла нет.
- После мержа PR файл задачи не удаляется — он остаётся историей решения (`Статус: done`).

Статусы: `todo`, `in-progress`, `blocked`, `done`. Остановленная задача становится
`blocked` с указанием, где и почему встала.
